Slidex 工作台 1.1 — 由你点击连接和执行

使用步骤
1. 双击“Slidex工作台.app”。它会在默认浏览器打开本机工作台。
2. 保持你的 Chrome for Testing 已打开，填写它的本机调试地址，例如 http://127.0.0.1:9222。
3. 点击“连接 / 刷新页面”，再从列表选择要操作的标签页。
4. 点击“在选中页面执行一次”。程序此时才调用 Slidex，运行时请不要同时操作这个标签页。
5. 如需中断，点“停止本次执行”，等待任务返回停止结果。
6. 使用完毕点“关闭服务”，再关闭工作台标签页。原 Testing 浏览器不会被工作台关闭。

连接条件
Testing 必须已经开启远程调试，端口需与它启动时使用的端口一致。
9222 只是默认填写值，不代表已经检测到你的浏览器端口。
如果没有开启调试，无法直接热连接。需你先保存工作，再自行按浏览器的调试启动方式重新启动。
工作台不会替你重启浏览器，不导入普通 Chrome 的 Profile 或 Cookie。
只接受 http://127.0.0.1:端口 或 http://localhost:端口，不支持远程机器地址。

能力与结果
使用本机 Slidex 0.6.28，当前接入其内置阿里云 NC / 极验适配器。
不同版本、定制页面、其他验证码类型可能不支持。不支持时停止，不自动尝试其他路径。
每次点击只执行一次，不自动重试，不定时运行；“执行”可能向目标网站提交一次验证动作。
Passed / Failed：适配器收到选中挑战所在 frame 中本次新请求的成功 / 失败反馈。
Unknown：没有收到可确认反馈、超时、页面变化或运行异常；请看原页面，不等于成功。
Unsupported：未找到适配元素，或图片、尺寸不满足识别条件；没有执行拖动。
Cancelled：任务已停止。若连接在拖动时突然断开，请到原页面检查鼠标和页面状态。
适配器反馈不保证整个页面或登录完成；多个挑战共享同一 frame 时仍需人工核对结果归属。

隐私与运行
打开工作台只启动本机服务，不会自动连接 Testing 或执行。
标签页列表只显示标题和网址来源（不展示路径/查询参数）。完整网址仅用于内存中的页面身份核对。
程序不导出 Cookie、图片或验证响应正文，不保存页面操作日志。JSON 导出由你手动点击。
应用自带运行环境，不依赖原项目 work/venv；不创建开机启动项。

其他程序接入
展开“API 接入”，手动显示本次 base_url 和 token；详见同目录“Slidex接口说明.txt”。
token 仅用于这次本机服务，服务关闭后失效；不要把它交给不信任的程序。

本次交付验证范围
检查本机接口、输入/并发/取消/超时边界、界面状态逻辑和应用启动。
按你的要求，没有连接或操作你当前的 Testing 浏览器，也没有执行真实网站滑块。
首次真实连接和具体网站效果，由你在工作台点击确认。
